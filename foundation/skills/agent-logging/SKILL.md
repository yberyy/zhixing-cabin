# Agent Logging

更新 `foundation/logs/development.md`，在同一日期下记录：

- 决策及其理由，尤其是会约束未来实现的选择。
- 实际完成的验证与结果，不把计划写成已验证。
- 仍会影响用户或下一位开发者的遗留项。

保持条目短而可追溯。不要记录密钥、访问令牌、用户私密内容或仅在当前会话有意义的过程信息。若行为或接口改变，同时更新对应 PRD、架构说明或 OpenAPI 契约。
